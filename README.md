# 안단테 지자체 안내

안단테가 이 저장소의 `guides.json`을 읽어 앱 안에 보여 줍니다.

공개 저장소인 이유: 휴대폰 앱은 GitHub에 로그인하지 않습니다. 비공개로 바꾸면 앱이 새 글을 받지 못합니다.

## 고치는 법

1. `guides.json`을 수정합니다.
2. main 브랜치에 저장합니다.
3. 앱을 다시 열면 그 내용으로 바뀝니다. 앱을 다시 설치하지 않아도 됩니다. 설치본이 2.7 이상이어야 합니다.

소개 문장은 지자체나 지역 관광 기관 공식 페이지에 있는 문장만 넣으세요. 없는 설명은 만들지 마세요.

## 항목

- `id` 고유한 영문 아이디
- `title` 장소 이름
- `summary` 공식 소개를 짧게 옮긴 문장
- `area` 경기, 서울, 인천처럼 광역
- `city` 시·군 이름
- `office` 글을 쓴 기관
- `href` https로 시작하는 공식 페이지
- `address` 주소. 없으면 빈 문자열
- `lat` `lon` 위도·경도. 없으면 null

`updated`는 `YYYY-MM-DD`, `note`는 출처를 한 줄로 적습니다.
